📈 曲线怎么读？

黑色粗线为真实使用率，彩色虚线为各模型预测。二者越贴合，说明该模型越能还原这间自习室一天中的使用节奏。

从真实曲线可见：使用率在一天内“有峰有谷”，高峰往往出现在深夜 0 时前后与晚间 20–21 时。

预测值整体向均值靠拢：模型能抓住“大致趋势”，但很难复现当天突变——这是模型波动解释力约四成的直接体现。

🔬 交叉验证如何选模型？

时间序列 3 折交叉验证（CV，291,456 条样本）对比线性回归 / 岭回归 / HistGB：三者 RMSE 均在 0.27–0.31，R² 在 0.36–0.47；其中岭回归与线性回归精度几乎持平，因带 L2 正则（alpha=100）更稳、泛化风险更低，故后端预测接口采用 pred_Ridge。

随机森林因时间外 R² 为负且训练耗时较长，未纳入时间序列交叉验证候选。

📉 为什么“更强的模型”反而更差？

随机森林、梯度提升在训练集拟合能力强，但对时间外（未来）数据泛化差：测试 R² 为负意味着预测比“直接取历史均值”还差。

本项目刻意保留并展示这个“反面结果”，提醒：真实部署前必须做时间外验证，而不是只看训练精度。

拥挤度等级口径

🔥 爆满：预测使用率 ≥ 50%，基本满座

🧡 热门：35% ≤ 使用率 < 50%，座位紧张

💙 适中：20% ≤ 使用率 < 35%，有空座但陆续有人

💚 空闲：使用率 < 20%，随到随学

📋 预测口径与局限（诚实说明）

· 预测输入：自习室编号、日期、小时；目标：该时段使用率（0–1）。
· 数据为历史回归预测结果（reg_predictions.csv，2024-12），可用于交互演示与效果回看。
· 模型整体仅能解释约四成波动，适合做趋势参考而非精确断言；择时择地请结合实际预约页面实时判断。
· 数据规律对现实选择的更多启发，见项目介绍 /about.html。
